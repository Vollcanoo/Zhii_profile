# Zhihan Dai — Bilingual Portfolio

Two separate, complete language versions in the same Nordic-inspired visual system:

- `index.html` — 中文版
- `en.html` — English version

The header language button navigates between versions while retaining the current section anchor. Open either file locally or deploy both to a static host such as GitHub Pages. The two included game pages live in `projects/`.

## Project links: explicit allowlist

External project links are limited to URLs supplied by the site owner:

- SleepGuard — https://github.com/Vollcanoo/sound_sleep
- Securities matching system — https://github.com/Vollcanoo/SmartSecuritiesSystem
- Compiler — https://github.com/Vollcanoo/fascinating_compiler
- Text2SQL — https://github.com/Lilian823/Text2sql

Local game links point only to files included in this bundle:

- `projects/unnoticed-corner.html` — the redesigned version of the supplied Douyin hackathon game
- `projects/power-outage.html` — the supplied Bitsy game export

The two playable games have visible card-level play links in both language versions, as well as links in their detail dialogs.

**MindPath, Disney / Enchanted Lantern, and ReID have no public link.** Their cards only open an on-page description; a small localized label says no public link is available. No inferred repositories, demo URLs, or placeholder links are added.

## Publishing

Upload `index.html`, `en.html`, `projects/`, and `README.md` together to a GitHub Pages repository. Select Settings → Pages → Deploy from a branch.

Google Fonts are optional; system-font fallback works without an Internet connection.
